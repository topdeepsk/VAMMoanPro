#### 速度 → 增益（Slap sound gain）

拍击声的最终音量 = `Slap sound volume × gain`，其中 `gain` 由触发瞬间的相对速度决定。设滑条值为 `g`（0–0.5）：

```
v < 0.1                     → 不播（原逻辑，与增益无关）
v ≥ 0.1                     → gain = 1 + 4 × g × (min(v, 0.8) − 0.35)
```

这是一条**固定穿过 (0.35 m/s, 1.0×) 的直线**，`g` 只控制斜率：

- `g = 0`：斜率 0，全程 1.0×（等于关闭，老场景默认值）
- `g = 0.5`：斜率 2.0/(m/s)，即 0.1 速度 0.5×、0.35 速度 1.0×，之后每多 0.25 m/s 涨 0.5×
- 速度上限 **0.8 m/s**：超过后按 0.8 计算，`g=0.5` 时最大 1.9×（与默认音量 0.5 相乘为 0.95，不削波）

| 相对速度 (m/s) | g=0 | g=0.25 | g=0.5 |
|---|---|---|---|
| 0.10 | 1.00 | 0.75 | 0.50 |
| 0.20 | 1.00 | 0.85 | 0.70 |
| 0.35 | 1.00 | 1.00 | 1.00 |
| 0.50 | 1.00 | 1.15 | 1.30 |
| 0.80 及以上 | 1.00 | 1.45 | 1.90 |

注意增益只影响**音量**，不影响强度分档（`Sound min/max intensity` 仍然按原始速度算出的 1/2/3 档选样本）。另外它还以 `Pelvic slap change gain` 这个非存档参数暴露给 Timeline / 动画事件，可在运行时动态改。

## 三、存档与恢复的几个要点

1. **只存改动过的值**：`JSONStorableFloat.StoreJSON` 里有 `_val != _defaultVal` 判断，所以和默认值相同的参数不会出现在场景 JSON 里。你的 `正常场景.json` 里 VAMMoan 条目只有 16 个键，就是这个原因。
2. **缺什么就回什么默认值**：`RestoreFromJSON(..., setMissingToDefault: true)` 会把文件里没有的参数设回构造时写死的默认值（`val = _defaultVal`），并触发回调。
3. **插件值最终覆盖人物值**：场景恢复时，人物原生 storable（`HeadAudioSource` 索引 98、`JawControl` 134）先恢复，插件 storable（`plugin#3_...` 索引 143）最后恢复，所以 `Voice volume` / `Voice pitch` 等以插件存的为准，并会再写一次到人物音源。
4. **`Init()` 里的"读回"只在新增插件时有效**：`VAMMVolume.val = headAudioSource.GetFloatParamValue("volume")` 这类赋值执行时，人物的 `HeadAudioSource` 还没恢复（它是 prefab 默认值），所以载入场景这条路上读到的是 1/1，随后被插件的恢复覆盖；只有"给活场景里的人物新加插件"时读到的才是真实值。
5. **三个音效开关在场景载入时不会立刻建触发器**：`enablePelvicSlapCallback / enableSquishesCallback / enableBlowjobCallback` 开头都有 `if (isLoading || !voiceInitialized) return;`，所以载入时只是把勾打上，真正建 AudioSource 和触发器要等 `FixedUpdate` 的初始化段（`vammoan.cs:1060-1096`）。

## 四、容易误判的几项

| 现象 | 原因 |
|---|---|
| 面板上有 `Turn Off Speed` 但怎么滑都没变化 | 源码里没有任何逻辑读取该参数（`vammoan.cs:618-621`） |
| `arousalRateCallback` / `VAMMBreathingEnabledCallback` / `VAMMPauseCallback` 是空函数 | 回调只用来占位，真实值在 `FixedUpdate` 里直接读 `.val`（`2413`、`1727`、`1322/1341`） |
| 改了声效音量拉到 2 以上会"更响但发糊" | 拍击/水声/口交的音量直接当 `volumeScale`，采样超 ±1 削波；人声同理，只是 `AudioSource.volume` 那层被钳在 1 |
| `Slap sound gain = 0` 时拍击声完全不受速度影响 | 这是设计如此：0 表示"关闭动态增益"，不是静音。要静音请关 `Enable pelvic slap` 或把 `Slap sound volume` 拖到 0 |
| 改了 Voice pitch，人物原生 Audio 面板里的 pitch 过 0.7 秒又跳回来 | `FixedUpdate` 每 0.7 秒把 `headAudioSource.pitch` 强制同步成插件值（`vammoan.cs:1123-1124`） |
| 关掉 auto-jaw 后嘴还在动 | 该开关只关 `JawControl` 的音频驱动和 `AutoJawMouthMorph`，其它口型插件（Embody / Lipsync）仍在驱动 |
