# VAMMoan 音频目录说明

> 对应代码：`src/vammoan_voices.cs`（索引 / 解码）、`src/vammoan_voice.cs`（配置读取 / 取样）、`build.py`（打包前校验）。
> 统计时间：2026-11-09，基于当前 `audio/` 目录实测。

---

## 一、目录总览

```
audio/
├─ jsondb/
│  ├─ Abby/voice.json                       每个音色一份配置
│  ├─ Claire/voice.json
│  ├─ … （共 13 个音色目录）
│  └─ voice-shared.json                     共用音效配置（所有音色共用）
└─ voicebundle/
   ├─ voices/
   │  └─ abby/ … yumi/                      音色目录
   └─ voices-shared/                        按类别分 5 个子目录
      ├─ kissing/
      ├─ breathing/
      ├─ blowjob/
      ├─ pelvicslap/
      └─ squishes/
```

几个必须知道的事实：

- **音色列表来自 `jsondb/` 的子目录名**。`Voices` 构造函数枚举 `audio/jsondb` 下的目录，每个目录名就是一个音色（下拉里显示的名字），同时决定去哪读 `voice.json`。
- **音频统一为 `.ogg`**（libvorbis `-q:a 2`，单声道，单个文件约 15–25 KB），2332 个共 36 MB；此前是 2562 个 wav、286 MB。
- **音频目录名必须是音色名的小写**：`Abby` → `voicebundle/voices/abby/`（代码里 `name.ToLowerInvariant()` 拼接）。
- 目录名叫 `jsondb`，但里面已经是标准 `.json`（早期是 VaM 的 `.jsondb`，改名后目录名保留）。

## 二、文件是怎么被匹配到的

这一节是改素材时最容易踩的坑。

1. **只认文件名（不含扩展名）**。`voice.json` 里写的是
   `"audio": "Assets/VAMMoan/Ella/m2-02.ogg"`，
   代码只取 `m2-02` 去索引里查，所以磁盘上叫 `m2-02.ogg`（或 `m2-02.wav`）都能命中。`.ogg` 这个后缀只是延用了原 AssetBundle 的资源名，**不是**强制要求格式。
2. **索引范围**：音色目录只看本层（`depth = 0`），共用目录向下展开 2 层（`depth = 2`，即 `voices-shared/<类别>/`）。
3. **支持的格式**：`.wav .ogg .mp3 .mp2 .mp1 .aif .aiff .aifc`（BASS 内核原生支持的）。`flac / wma / aac / m4a / ape / opus` 需要额外解码器，会被跳过（`build.py` 只给警告）。
4. **同名多格式**按上面的顺序优先（`wav > ogg > aiff > …`），不会受文件系统遍历顺序影响。
5. **解码后 `clip.name` 会被设成文件名**，播放时按 `clip.name` 匹配 → 同一个音色目录内**不能有重名**（不同扩展名同名算同一个，取优先级高的）。

## 三、`jsondb/<音色>/voice.json`

### 3.1 整体结构

```json
{
  "config": {
    "informations": "<b>Gender: </b> Female\n<b>Quality: </b> 5/5 …",
    "settings": { }
  },
  "moans": [
    { "audio": "Assets/VAMMoan/Abby/m0-01.ogg", "minArousal": 0.0, "maxArousal": 0.0 }
  ],
  "orgasms": [
    { "audio": "Assets/VAMMoan/Abby/o-01.ogg" }
  ],
  "perpetual_orgasms": [
    { "audio": "Assets/VAMMoan/Abby/po-01.ogg" }
  ]
}
```

`config.informations` 是面板上显示的那段文字。`moans` / `orgasms` / `perpetual_orgasms` 三个列表都**不能为空**（`build.py` 会拦）。

### 3.2 `config.settings` 字段

| 字段 | 示例 | 作用 |
|---|---|---|
| `gender` | `0` | `0` = 女，`1` = 男。决定用 `voice-shared.json` 的 `female` 还是 `male` 段 |
| `intensitiesCount` | `5` | 强度档数，运行时写进 `VAMM IntensitiesCount` 供外部插件读取 |
| `moanRepetitionBuffer` | `9` | 去重缓冲长度：最近 N 条播放过的呻吟不会再被抽到 |
| `overlapLengths` | `{"0":"-0.025", "1":"-0.025", …, "6":"-0.010"}` | 按 arousal 档位（键 `0`–`4`、`6`）配置的衔接重叠量（秒）。负数表示提前接上下一条，用于让呼吸动画与音频对齐 |
| `jawHoldSpring` | `86` | 下巴关节弹簧刚度（"Set optimal auto-jaw" 时写入 `JawControl.spring`） |
| `jawHoldDamper` | `2` | 下巴关节阻尼（写入 `JawControl.damper`） |
| `audioDriveMultiplier` | `110` | 响度 → 张口角度的倍率（写入 `driveXRotationFromAudioSourceMultiplier`） |
| `audioDriveExtraAngle` | `0` | 无声时的基础角度（写入 `…AdditionalAngle`） |
| `audioDriveMaxAngle` | `-10` | 最大张口角度，负数表示张嘴方向（写入 `…MaxAngle`） |

### 3.3 `moans[]`

| 字段 | 说明 |
|---|---|
| `audio` | 资源路径，只有文件名部分有效 |
| `minArousal` / `maxArousal` | 允许播放的 arousal 区间。运行时 `normalizedArousal = floor(当前 arousal)`，满足 `min ≤ n ≤ max` 才会被抽到 |

实际数据里绝大多数是 `min == max`（按 0/1/2/3/4 五档分组），也允许跨档，比如 Ella 的 `m2-02` 是 `2.0 – 4.0`，表示 2、3、4 档都能用。

抽取流程（`vammoan_voice.cs:GetTriggeredAudioMoan`）：

1. 过滤掉最近 `moanRepetitionBuffer` 条里出现过的同名片段；
2. 过滤掉 arousal 区间不匹配的条目；
3. 剩下的随机取一条，把名字记进 `lastMoanList`；
4. 如果一条都不剩（该档素材太少时会发生），**回退到 `moans[0]`**。

### 3.4 `orgasms[]` / `perpetual_orgasms[]`

只有 `audio` 一个字段。`orgasms` 是高潮时播一次就结束；`perpetual_orgasms` 是"持续高潮"状态下反复抽用的池子，同样有各自的去重列表（`lastPerpOrgList`）。

### 3.5 同一段音频可以被多处引用

数量上会看到"引用条数 > 磁盘文件数"：13 个音色合计 **2205 条引用对应 2102 个文件**。原因是同一段音频可以同时出现在多个列表里，例如 Ella 的 `m2-02` 既是 `moans`（2–4 档）又是 `perpetual_orgasms`。磁盘上只需要一份。

## 四、`jsondb/voice-shared.json`

所有音色共用的一套音效，按性别分两段，再加上不分性别的撞击/水声。

```
config         { informations: "Shared voice assets for VAMMoan." }
female         { kisses: 14, breathes: 5,  blowjobs: 54 }
male           { kisses: 14, breathes: 4,  blowjobs: 54 }
pelvicslaps    41 条，intensity 1/2/3 = 9/12/20
squishes       16 条，intensity 全为 1
squishes_penis 28 条，intensity 全为 1
```

| 段 | 字段 | 谁在用 / 怎么筛 |
|---|---|---|
| `female` / `male` → `kisses` | `audio`、`minArousal`、`maxArousal` | 亲吻状态（arousal 100）循环播放。代码里**只用 `audio`**，`minArousal/maxArousal` 是历史字段，不参与筛选 |
| … → `breathes` | 同上 | 呼吸状态（arousal -1）循环播放，同样只用 `audio` |
| … → `blowjobs` | `audio`、`intensity` | 口腔水声。`intensity` 目前**全为 0**，调用处固定传 `0f`，等于不分档 |
| `pelvicslaps` | `audio`、`intensity` | 拍击声，**真的分档**：相对速度 < 0.2 → 1 档、0.2–0.35 → 2 档、> 0.35 → 3 档，再被面板的 `Sound min/max intensity` 钳位 |
| `squishes` | `audio`、`intensity` | 女性阴部水声（挂在 `LabiaTrigger`），`intensity` 全为 1，调用处传 `1` |
| `squishes_penis` | `audio`、`intensity` | 男性 / alt-futa 的阴茎水声，同样固定传 `1` |

`female` / `male` 的选择由 `voice.json` 的 `settings.gender` 决定（`GetAudioGenre()`：0 → `female`，1 → `male`）。也就是说**男性音色（Seth）只会用到 `male` 段的亲吻/呼吸/口交音**，女性音色用 `female` 段；拍击和水声两段共用。

## 五、改素材的操作清单

**加 / 换一段音频**

1. 把文件放进 `voicebundle/voices/<音色小写>/`（共用音效放 `voicebundle/voices-shared/<类别>/`）；
2. 在对应 json 列表里加一条 `{"audio": "Assets/VAMMoan/<音色>/<stem>.ogg", …}`——扩展名随便写，**stem 必须和磁盘文件名一致**；
3. 同一个音色目录内不要重名（重名只会命中优先级高的那个）。

**新增一个音色**

1. 建 `jsondb/<音色名>/voice.json`（`config.settings` 里 `gender` 必填 0/1）；
2. 建 `voicebundle/voices/<音色名小写>/` 放音频；
3. 重载插件，音色列表会自动多一项（列表在 `Voices` 构造时从 `jsondb` 子目录生成）。
